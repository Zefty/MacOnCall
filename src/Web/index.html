A few things to know.

Will my settings reset when I unplug?+

MacOnCall saves your mode and session deadline. While the app is running, it listens for power changes and wake events, then reapplies sleep prevention if your session is still active.

Does it work with the lid closed?+

MacOnCall attempts to prevent lid-close sleep, but support varies by Mac and macOS version. The built-in display still turns off when the lid is closed. Check the behaviour on your own Mac before relying on it.

What do I need to run it?+

macOS 14 or later on Apple Silicon or Intel. Download the DMG from GitHub Releases and move MacOnCall to Applications. Current releases are unsigned. No account or administrator password is required for sleep prevention.
